C9 Prescription Import

Import optical prescriptions from CSV or XLSX files into Odoo. Supports 204,000+ row files with batched processing.

  • Maps CustomerId to res.partner.c9_customer_id (preserves leading zeros and letters, e.g. "0002", "AA01", "CASH")
  • Stores all 49 source fields
  • Unmatched rows are imported and flagged, never discarded or mis-assigned
  • Skips exact duplicates on re-import (Doctype/Docno/WH/CustomerId/Date)
  • Customer smart button shows each customer's prescriptions
  • Import history with matched/unmatched/error statistics
  • Menu: Sales → Prescriptions
